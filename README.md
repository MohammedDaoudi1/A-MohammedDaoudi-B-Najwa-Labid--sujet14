# AI Software Architect Agent

## Présentation

Agent architecte logiciel est un agent intelligent
permettant d'analyser un cahier des charges et de proposer
des architectures logicielles adaptées.

## Fonctionnalités

- Extraction des exigences fonctionnelles.
- Extraction des exigences non fonctionnelles.
- Analyse des contraintes.
- Proposition d'architectures.
- Comparaison multicritère.
- Recommandation des composants techniques.
- Génération de diagrammes.
- Génération de rapports.

## Technologies

- Python
- NLP
- LLM
- RAG
- FastAPI
- Streamlit
- Pytest
